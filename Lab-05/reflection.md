# Reflection

### 1. What did you learn from static code analysis?

I learned that static analysis tools can find coding mistakes, code-quality problems, and possible security issues without running the program.

### 2. Which tool was most useful?

Pylint was useful for checking code quality and giving a score. Bandit helped identify possible security problems, while Flake8 checked formatting and style issues.

### 3. What problems did you fix?

I fixed problems related to coupon discounts, trial expiry, payment retries, billing dates, hardcoded secrets, encryption, XML parsing, webhook verification, and HTML escaping.

### 4. What did you learn about secure coding?

I learned to avoid hardcoded secrets, validate input, use secure random values, protect sensitive data, and handle user input carefully.
